QuickDoc は macOS の Finder Sync 拡張機能を活用したユーティリティです。Finder のコンテキストメニューに実用的な「新建文件」サブメニューを追加します。v1.3 以降では Finder のツールバーにも QuickDoc を追加でき、ツールバーから直接ファイルを作成できます。

## v1.8.0 の新機能

1. 設定ウィンドウの初期サイズを 960×720、最小サイズを 880×660 に縮小しました。
2. 設定画面を簡素化し、システム標準の折りたたみ可能なサイドバーと整理された各ページにしました。
3. 初期状態ではオフの実験的項目「外置硬盘右键菜单（实验性）」を追加しました。一般的な利用ではオンにしないことを推奨します。オンにすると外付けディスクのマウントポイントを監視し、Finder がそのディスクアイコンを QuickDoc のロゴで表示することがあります。オフに戻しても、Finder がそのディスクを読み直すまでアイコンが残ることがあります。アイコンの変化を避けたい場合はオフのまま、QuickDoc を Finder ツールバーに追加して使ってください。
4. このスイッチが右クリックメニューを追加するのは、`/Volumes/名前` に直接マウントされ、ローカルでブラウズ可能、DiskArbitration が内蔵ではないと報告し、プロトコルが USB、Thunderbolt、PCI Express、SD、FireWire、SATA、SAS、SCSI、ATAPI のいずれかであるボリュームだけです。ディスクイメージ、ネットワークボリューム、シミュレータのボリュームは対象外です。すべての外付けディスクやファイルシステムで使えることを保証するものではありません。

## v1.7.7 の新機能

1. ツールバーのメニューを組み立てる際に Finder へ同期 AppleEvent を送っていたため、メニューが「待機中…」のまま止まる問題を修正しました。
2. 監視対象外のフォルダ（外付けボリュームを含む）でツールバーから操作したとき、作成先がホームフォルダへ誤って戻る問題を修正しました。作成先を確定できない場合は操作を中止し、別の場所へ書き込みません。
3. メインアプリに Finder 自動化の entitlement を追加し、macOS が通常の手順で QuickDoc に Finder の制御許可を求められるようにしました。照会に失敗した場合は AppleEvent の数値エラーを記録します。

## v1.7.6 の新機能

## QuickDoc を使う理由

- 別のアプリを開かずに Finder から一般的なファイルを直接作成
- 独自テンプレートからファイルを作成し、よく使う文書スタイルを毎回作り直す手間を減らせます
- 実際に使うファイル形式だけを表示
- 独自のワークフローに合わせてカスタム拡張子を追加
- 視覚的なプレビューでコンテキストメニューを整理
- 同じ右クリックメニューから現在のフォルダをターミナルで開く、またはパスをコピー
- 同名ファイルがある場合は番号付きの接尾辞を自動追加して上書きを防止

## 使用方法

1. `QuickDoc.app` を起動
2. 「权限与扩展」ページを開くか、`打开扩展设置` をクリック
3. macOS の Finder Extensions で `QuickDocFinderSync` を有効化
4. Finder のフォルダ背景、選択したフォルダ、またはデスクトップを右クリック
5. `新建文件` を選択し、必要なファイルを作成

設定で有効にすると、Finder のトップレベルのコンテキストメニューに `在终端中打开` と `复制当前路径` も表示されます。コピー、ペースト、カット、完全削除は個別に有効化でき、「快捷操作」にまとめるか、第1階層メニューへ展開できます。

## インストール

最も簡単な方法は GitHub Releases から最新の `QuickDoc-<version>.dmg` をダウンロードし、開いた後に `QuickDoc.app` を `Applications` にドラッグすることです。

続いて：

1. `QuickDoc.app` を開く
2. `权限与扩展` ページに移動するか、`打开扩展设置` をクリック
3. `システム設定 > プライバシーとセキュリティ > ログイン項目と機能拡張` で `QuickDocFinderSync` を有効化
4. メニューがすぐに表示されない場合は QuickDoc の `立即重启 Finder` を使用

v1.4.0 をインストールすると、以降のバージョンは一般設定ページ下部の `检查更新` から確認できます。新しいバージョンが見つかると QuickDoc はインストール前に確認を求め、同意後にダウンロードと置き換えを行います。完了すると自動的に再起動し、アップグレード完了を通知します。

macOS で開発元を確認できないという警告が表示された場合は、Finder で `Control` キーを押しながらアプリをクリックし、`開く` を選択してください。配布物は ad-hoc 署名です。Developer ID 署名や公証はありません。

## ソースからビルド

Finder Sync 拡張機能は Command Line Tools だけではビルドできないため、QuickDoc には完全版の Xcode が必要です。

### 方法 1：1 つのコマンドでローカルビルドして実行

```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
./script/build_and_run.sh
```

このスクリプトは次の処理を行います：

1. `QuickDoc` アプリと Finder 拡張機能をビルド
2. Finder 拡張機能の登録を更新
3. Finder を再起動
4. `QuickDoc.app` を起動

初回起動後、macOS が拡張機能をまだ自動的に有効化していない場合は、`QuickDocFinderSync` を手動で有効にしてください。

### 方法 2：Xcode で手動ビルド

1. 必要に応じて一度実行：

```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

2. Xcode で `QuickDoc.xcodeproj` を開く
3. `QuickDoc` スキームを選択
4. `Run` をクリック
5. Finder Extensions で `QuickDocFinderSync` を有効化

## リリース成果物をビルド

ソースから `.app`、`.zip`、`.dmg` をパッケージ化するには：

```bash
./script/package_release.sh
```

成果物は `build/release/` に生成されます。

## トラブルシューティング

設定変更や再ビルド後に Finder メニューが更新されない場合は、Finder を再起動してください：

```bash
killall Finder
```

メニューをクリックしても反応しない場合は、操作中にアプリと拡張機能のログを確認してください：

```bash
log stream --info --style compact --predicate 'process == "QuickDoc" OR process == "QuickDocFinderSync"'
```
