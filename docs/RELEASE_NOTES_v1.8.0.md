# QuickDoc v1.8.0

## 更新内容

- 默认设置窗口缩小为 960×720，最小尺寸为 880×660。
- 设置界面做了简约化重设计，使用原生可收起侧栏，并整理了各个页面。
- 新增默认关闭的「外置硬盘右键菜单（实验性）」。不建议一般用户开启。开启后会监听外置硬盘挂载点，Finder 可能把磁盘图标显示为 QuickDoc Logo；关闭后，Finder 可能仍暂时保留已更换的图标，直到重新读取该磁盘。介意图标变化请保持关闭，建议将 QuickDoc 添加到访达工具栏使用。
- 该开关只为直接挂在 `/Volumes/名称`、本地且可浏览、DiskArbitration 报告为非内置，并且协议是 USB、Thunderbolt、PCI Express、SD、FireWire、SATA、SAS、SCSI 或 ATAPI 的卷提供右键菜单。磁盘映像、网络卷和模拟器卷不会加入。这不表示所有外置磁盘或文件系统都可用。

## 下载说明

- `QuickDoc-1.8.0.dmg`：推荐使用，打开后拖入“应用程序”文件夹即可覆盖更新。
- `QuickDoc-1.8.0.zip`：解压后将 QuickDoc 拖入“应用程序”文件夹即可。
- 安装包沿用既有发布方式：ad-hoc 签名，未使用 Developer ID，也未公证。首次打开时 macOS 可能提示无法验证开发者。
