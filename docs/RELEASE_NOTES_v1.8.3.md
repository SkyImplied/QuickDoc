# QuickDoc v1.8.3

## 更新内容

- 检查更新仍会先询问，确认后才从 GitHub 下载 ZIP。
- 确认后打开紧凑的独立更新窗口，显示进度、已下载和总大小，并可以取消。下载过程中主程序保持打开。
- 更新包会核对 GitHub 发布记录里的 SHA-256，以及主程序、访达扩展和登录项的身份与版本，再执行 `codesign --verify --deep --strict`。
- 只有点击「安装并重启应用」后，QuickDoc 才会替换并重新打开。
- 替换失败时恢复刚才的版本。
- 已安装的 v1.8.3 之前版本在确认后仍会按那个版本自己的流程立刻替换。这次发布的 ZIP 仍使用原来的文件名和校验方式，供那些版本下载。

## 下载说明

- `QuickDoc-1.8.3.dmg`：推荐使用，打开后拖入“应用程序”文件夹即可覆盖更新。
- `QuickDoc-1.8.3.zip`：解压后将 QuickDoc 拖入“应用程序”文件夹即可。应用内更新也下载这个 ZIP。
- 安装包沿用既有发布方式：ad-hoc 签名，未使用 Developer ID，也未公证。首次打开时 macOS 可能提示无法验证开发者。SHA-256 和签名校验不能代替公证，也不会绕过 Gatekeeper。

## 验证范围

- 已用隔离测试核对下载、进度、取消、失败、无效包拒绝、替换和失败恢复。
- 已用真实发布包在临时目录核对提取、版本、架构和签名。
- 这次没有验证 Finder 菜单，也没有在“应用程序”文件夹里的已安装 QuickDoc 上执行更新。
