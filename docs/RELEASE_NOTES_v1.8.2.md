# QuickDoc v1.8.2

## 更新内容

- 修复跟随系统时地区优先于文字，导致 `zh-Hans-HK` 等简体中文被误识别为繁体中文。
- 修复没有单独选择语言时，继承的系统 `AppleLanguages` 被当成手动选择。
- 已经在软件里选择的语言会保留。

## 下载说明

- `QuickDoc-1.8.2.dmg`：推荐使用，打开后拖入“应用程序”文件夹即可覆盖更新。
- `QuickDoc-1.8.2.zip`：解压后将 QuickDoc 拖入“应用程序”文件夹即可。
- 安装包沿用既有发布方式：ad-hoc 签名，未使用 Developer ID，也未公证。首次打开时 macOS 可能提示无法验证开发者。
