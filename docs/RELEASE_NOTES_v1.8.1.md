# QuickDoc v1.8.1

## 更新内容

- 新增繁體中文、English 和日本語，并保留简体中文。
- 默认跟随 macOS 首选语言，也支持地区变体。可以在设置中选择「跟随系统」、简体中文、繁體中文、English 或 日本語。
- 设置窗口和菜单会立即使用所选语言。访达扩展会在下次显示菜单时使用同一语言。

## 下载说明

- `QuickDoc-1.8.1.dmg`：推荐使用，打开后拖入“应用程序”文件夹即可覆盖更新。
- `QuickDoc-1.8.1.zip`：解压后将 QuickDoc 拖入“应用程序”文件夹即可。
- 安装包沿用既有发布方式：ad-hoc 签名，未使用 Developer ID，也未公证。首次打开时 macOS 可能提示无法验证开发者。
