# QuickDoc v1.7.7

## 更新内容

- 修复 Finder 工具栏菜单在组菜单时同步向访达发送 AppleEvent，导致菜单出现「正在等待…」并卡住的问题。
- 修复未监视目录（包括外置磁盘）上使用工具栏时，目标可能错误落到用户主目录的问题。无法确定目标文件夹时会取消操作，不再静默写入其他目录。
- 为主应用补上访达自动化 entitlement，使 macOS 可以按正常流程请求 QuickDoc 控制访达的权限；查找失败时会记录 AppleEvent 数字错误码。

## 下载说明

- `QuickDoc-1.7.7.dmg`：推荐使用，打开后拖入“应用程序”文件夹即可覆盖更新。
- `QuickDoc-1.7.7.zip`：解压后将 QuickDoc 拖入“应用程序”文件夹即可。
- 安装包沿用既有发布方式：ad-hoc 签名，未使用 Developer ID，也未公证。首次打开时 macOS 可能提示无法验证开发者。
